# Šachové aplikace – rozcestník

Úvodní stránka s odkazy na všechny aplikace, krátkým popisem a návodem.
Běží na GitHub Pages: https://slivam24.github.io/portfolio/

Celá stránka je jeden soubor `index.html` (bez buildu). Novou aplikaci přidáš zkopírováním
jednoho bloku `<article class="card">…</article>` a úpravou textů a odkazů.
